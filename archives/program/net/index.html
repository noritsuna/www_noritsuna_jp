Java Language Conversion Assistant

JavaのコードをC#に変換してくれるという、すばらしいツールです。

諸事情により、手抜き、、、もとい、Javaのコードがどのように変換される
のか、コピペ、、、もとい、読んでみたく思い、かようなツールを利用して
みました。

そのすばらしき顛末です。

●準備
1，まずは、ここからGet。
Microsoft Java Language Conversion Assistant 2.0


2，インストール！！！
VSのアドインとして組み込まれます。


3，VisualJ++でプロジェクトを作成。
そこに変換させたいJavaファイルを読み込ませます。


4，「ファイル」→「開く」→「変換」
変換を実行します。設定はデフォルトのままを使用。


●結果
「解析に失敗しました。」と、エラー吐いて落ちます。。。
コアファイル見ても、意味不明な文字列がならんでいるだけ。。。

う〜ん、意味がわからん。

いろいろと調べてみると、「JDK1.2 の一部のみサポート」ということらしい。
もしかしたら、この辺に引っかかっているのかも。。

でも、変換できないモノは、そのまま出力するって書いてあるんだけどなぁ。


●再挑戦
さらに、調査したところ、Ver.3.0βなるものを発見。
JDK1.3をサポートと書いてあるので、こちらにて、再度挑戦してみる。

Microsoft Java Language Conversion Assistant 3.0 beta


●結果2
ダメです。やっぱ、同じエラー吐いて落ちます。

やはり、高度なプログラムは変換できないんでしょうか？
↓が、ソースの「全て」なんですが。。。どうやら、JLCA君には、難しい
プログラムだったようです。＿|￣|○　ガックシ・・・
