2005年03月02日

ネットワークトラブル

自宅サーバ環境にて、ここ数日のうちに80％くらいの確率でネットワーク
接続エラーになる現象が発生。（日に日に影響範囲が広がる）
現象をまとめると、下記の感じ。

・外部からsmtpやimap,httpに接続すると接続エラー
が80％くらいで出る
　(なので、時々はつながる)
・同じサーバでも、内部からのアクセスは、ルータを経由
すると同現象が出る
・同じサーバでも、内部からのアクセスで、直接接続すると
現象が出ない
・内部から外部へアクセスは、エラーが出ない。

この辺のことより、ハブが逝かれたと推測するが、至る所に7個も
ハブが存在するため、ネットワーク構成を考えながらどの物理経路が
怪しいかを考えること10分、アップリンクとダウンリンクのLEDが
ちぐはぐに点滅しているハブを発見。

用意したハブに取り替え、無事、復旧。ヽ（´▽｀）ノ

久しぶりのレイヤー1の作業でした。

ご迷惑をおかけした皆様、どうも、すみませんでした。ぺこ <(＿ ＿)>

NIS2005とトルネードWeb

どうやら、NortonInternetSecurity2005とAirH"用Venturi Client(トルネードWeb)の
相性がよろしくない模様。

しばらく、HTTP、HTTPS経由で通信を行っているとどちらかがフリーズして
HTTP、HTTPS経由のアクセスが一切出来なくなります。
(まぁ、両方ともHTTP Proxyとして動作するものですからね。競合する可能性は
高いわけで。)

この状態になったら、落ちている方を再起動すると復活します。
サービスとして登録されているので、そちらから再起動できます。

・Symantec Network Proxy
・Venturi2 Client

「回復」タブの中にある、落ちたらサービスを再起動するオプションをつけて
おくとましになる模様です。
