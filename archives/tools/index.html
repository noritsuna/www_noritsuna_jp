思っていたところに、

自分のPCは宝の山だった――デスクトップ情報検索ソフト
「ConceptSearch」が教えてくれたこと

こんな記事を発見しました。
そこで、早速、試してみようかと思いますが、一種類ではなんなので、
DesktopSearchの雄

Google Desktop Search

も、試してみました。

・ソースコード（C、C++、C#、Java）
・ブラウザのキャッシュ（IE、FireFox）
・メール（Becky!、IMAP4）

あきらかに、ConceptSearch に一日の長がある感じです。
ただ、これがどの程度使えるかですね。

・ConceptSearch・・・自然文検索
・Google Desktop Search・・・Google と同じ、単語単位



各検索対象物が、引っかかりそうなキーワードやキーフレーズを入力して
いったところ。。。

・ビジネス文書一式
Google Desktop Search は、だめ。
ビジネス文書一式が、全然、引っかからないです。やりかたがあるのかな？

・各種テキスト
こちらは、ともに、問題なく検索に引っかかるようです。

・ソースコード
こちらは、ともに、問題なく検索に引っかかるようです。

・ブラウザのキャッシュ
ConceptSearch は、引っかかるのですが、表示がよろしくない。
画像リンクが切れてたり、元サイトに飛べなかったりと。
Google Desktop Search は、この辺さすがで、ばっちりと表示され、かつ、
Google と同じ感覚で使えます。

・メール
ConceptSearch は、IMAPは非対応みたい。。。orz
Google Desktop Search は、Outlook系かFireFox系しか対応していないよう
です。さらに、噂では、日本語メールは無理だとか。。。

ただし、ConceptSearch は、テキストファイルとしては検索に引っかかりますので、
IMAPのキャッシュを引っかけることは可能です。
そのため、一応使えると言うところですが、Subjectが、デコードされないため
いまいちといったところです。

Google Desktop Search は、歯牙にもかからないという感じです。

・メッセンジャーのログ
ともに、全く検索できませんでした。

・検索エンジンとしての質
上記のモノたちがどのくらい希望にあったモノだったかというと、、、

ConceptSearch が、Google Desktop Search の2枚くらい上手という感じです。

たとえば、「見積もり」を検索した場合、

ConceptSearch は、「見積り」「見積」の送りなどを同一視しますが、
Google Desktop Search は、「見」「積」「も」「り」として、検索する様
です。

この差は、ビジネス文書において、非常に大きく検索結果に反映されます
ので、特筆すべき点ではないかと思います。


実際に引っかかったモノは、ConceptSearch は、

「これなら使える」

というくらいのレベルでしょうか？
絶賛と言うところには、もう一歩足りないという感じです。

Google Desktop Search は、

「日本語のモノが、少々厳しい」

というレベルでしょうか？
もう一歩、改善して頂きたいところであります。

※個人的なファイルが多いため検索結果画面は出せません。ぺこ <(＿ ＿)>
※私の検索の仕方が悪い可能性もあることは付け加えておきます。


●まとめ
当初の予想では、併用して補って使っていく感じかなとも思っていたのですが、
どう考えても、日本語検索がメインになると思われるため、ConceptSearch に
一日の長があります。
しかし、ConceptSearch は、6600円ほど、Google Desktop Search は、無料。

この差を、どう取るかだとおもいますが、個人的には、

「ConceptSearch 買え！」

という結論です。
メールとか文書とか良く迷子になる人は、是非、使ってみてください。

※あくまで、私の使用法上の感想です。人によって、検索対象物や検索法など
　違いがあるとも思いますので、体験版にて試用してみることをお奨めします。
