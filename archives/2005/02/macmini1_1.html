MACmini・基本のお勉強その1

オライリーのRunning Mac OS Xを、買って参りました。

これを参考に、ちまちまと遊んでいこうかと思います。




・キーボード
実を言うと、キーボードは、英語配列版HHK Lite2を使っています。

しかも、USB切り替え機でWindowsマシンと共有してるという状態です。

ですが、ちゃんと使えてます。
Windowsキーが、Appleキー（？）として認識されるため、まったく、問題
ありません。




・マウス
これは、ごくごく普通のホイール付き2ボタンマウス。
これも、Windowsマシンと兼用です。




・ソフトウェア・アップデート
すごいっすね、これ。
ソフトをインストールした後、自動で、デフラグをかけてくれるみたいです。
どのくらいの効果があるのかは、微妙ですが。(^-^;A

でも、実態は、portsのアップデートをしているだけだと思います。






・Mac OS X 10.3.8 Update（Delta）
http://www.itmedia.co.jp/news/articles/0502/10/news029.html
マイナーバージョンが出たみたいです。

MACminiが来てからの初マイナーバージョンアップです！

ということで、さっそく、ソフトウェア・アップデートを実行です。




ｷﾀ━━━━━━(ﾟ∀ﾟ)━━━━━━ !!!!!
Mac OS X 10.3.8 って、書いてありますよ。

バージョンアップ前

Mac OS X Version 10.3.7（Build 7T21）

バージョンアップ後

Mac OS X Version 10.3.8（Build 7U16）

ちゃんと、システム的にもアップデート完了したみたいです。
