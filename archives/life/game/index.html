●終了関連の関数
必要な関数は、下記の物となります。
これらを、main.c などにコピペしてください。

int exit_callback(void)
{
// Cleanup the games resources etc (if required)

sceKernelExitGame();

return 0;
}

#define POWER_CB_POWER 0x80000000
#define POWER_CB_HOLDON 0x40000000
#define POWER_CB_STANDBY 0x00080000
#define POWER_CB_RESCOMP 0x00040000
#define POWER_CB_RESUME 0x00020000
#define POWER_CB_SUSPEND 0x00010000
#define POWER_CB_EXT 0x00001000
#define POWER_CB_BATLOW 0x00000100
#define POWER_CB_BATTERY 0x00000080
#define POWER_CB_BATTPOWER 0x0000007F
void power_callback(int unknown, int pwrflags)
{
// Combine pwrflags and the above defined masks
}

// Thread to create the callbacks and then begin polling
int CallbackThread(void *arg)
{
int cbid;

cbid = sceKernelCreateCallback("Exit Callback", exit_callback);
SetExitCallback(cbid);
cbid = sceKernelCreateCallback("Power Callback", power_callback);
PowerSetCallback(0, cbid);

KernelPollCallbacks();
}

/* Sets up the callback thread and returns its thread id */
int SetupCallbacks(void)
{
int thid = 0;

thid = sceKernelCreateThread("update_thread", CallbackThread, 0x11, 0xFA0, 0, 0);
if(thid >= 0)
{
sceKernelStartThread(thid, 0, 0);
}

return thid;
}


●終了処理用コード
初期化が、終わったあたりに、下記の一行を追加するだけです。
これで、「HOME」ボタンを押すと、見慣れた画面が表示されます。

SetupCallbacks();

●終了処理用コード
さきほどの main.c 内、519行目から532行目までが、ファイル用の配列と構造体です。
必要に応じて、作成してください。

#define WAVFILEMAX_BG 8*1024*1024
char wavdata_bg[WAVFILEMAX_BG];
wavout_wavinfo_t wavinfo_bg;


使い方は、下記のような感じで、ファイル名と上記の構造体を渡して、
再生させます。
「0」と「1」があるのですが、BGMのようなループさせたい音とジャンプ音のような
一回のみ非同期で再生したい音というような感じで使い分けると思われます。(^-^;A


「0」のパターン


ret=wavoutLoadWav("op.wav",&wavinfo_bg,wavdata_bg,sizeof(wavdata_bg));
if (ret!=0) halt("op.wav load error");
wavinfo_bg.playloop=1; // ループします。
wavoutStartPlay0(&wavinfo_bg);
　　//終了処理
wavoutWaitEnd0();
wavoutStopPlay0();

「1」のパターン

ret=wavoutLoadWav("op.wav",&wavinfo_bg,wavdata_bg,sizeof(wavdata_bg));
if (ret!=0) halt("op.wav load error");
wavoutStartPlay1(&wavinfo_bg);
//終了処理
wavoutStopPlay1();

PSPプログラミング

最近、いろいろと忙しく情報してなかったら、いつの間にかPSPで
自作プログラムが動く環境が出来ているではないですか！！！

これは、さっそくということで、開発環境を構築してみましたので
その流れで引っかかりそうなところを抜粋して、書いておきます。


●必要なソフトのダウンロード
・Cygwin
http://cygwin.com/

・PS2Dev
http://ps2dev.org/files/PS2Dev_Setup.exe
http://nnoble.nerim.net/ps2dev/ps2dev-toolchain-mingw32-20050504.zip

PS2用の開発環境です。
これをベースに、開発環境を構築します。


・算譜職人さん作の HelloPSP R1 の ソースコード
http://anon.ug.to/sec/
http://anon.ug.to/sec/pub/hellopsp_src_Rel1.zip

こちらから、使えそうなコードを頂きます。(^-^;A
各ファイルの意味は、同梱されている readme.txt を参考にしてください。

mk.bat
font.c
pg.c
pg.h
outpatch.cpp
startup.s


・elf2pbp
http://www.internalreality.com/
PSP用elfファイルを EBOOT.PBP ファイルに変換するツール


●インストール
Cygwin と PS2Dev は、インストーラ付きですので、普通にインストールして
ください。

他の物は、任意のフォルダにまとめて保存してください。

私の開発用フォルダは下記のようになっています。

elf2pbp.exe
font.c
main.c ←これは、自分で作ったファイル
mk.bat
pg.c
pg.h
outpatch.exe
outpatch.cpp
startup.s



●コンパイル法
基本は、 mk.bat を叩くだけです。が、やはり、書き換える必要が
あります。
(Makefile とか作ってもOK！)

1行目 が、一応メイン関数があるファイルのコンパイルの指定ですので
これを自分の環境に合わせて書き換えます。

さらに、最後に

elf2pbp outp "Test Program"

を、付け足します。
これで、EBOOT.PBP が、生成されます。
第２引数の「"Test Program"」は、プログラム名となります。


・モジュール名の変更
startup.s の 59行目で変更できます。

.ascii "HelloWorld" #up to 28 char

ただし、これを行ってしまうと、outpatch.exe が、

modulename not found

とエラーを吐くようになります。
回避法は、outpatch.cpp の 6行目で、

#define str_modulename "HelloWorld"

と、モジュール名が指定されていますので、書き換えて、コンパイルし
直す必要があります。


●まとめ
これで、コンパイルできる環境が整いました。
あとは、API を調べて、面白そうな悪さを考えるだけです。(^-^;A

とはいっても、Network系のは、まだ、解析されてなさそうなので
先の話なのかなぁとか思いつつ、ちょっと、遊んでみようかと
思います。

・参考サイト
http://forums.ps2dev.org/viewforum.php?f=12
http://forums.ps2dev.org/viewforum.php?f=14




※注意事項
ファームバージョンが1.5以上だと、メモリースティックから起動
出来るプログラムが正規に暗号化された物じゃないとダメらしく
この開発環境でコンパイルした物では起動できないそうです。

こちらにも、こんな話も出てますし、かなり信憑性は高そうです。

こうなってくると、ファームバージョン1.0は、プレミアつくかしらん。(^-^;A
ちなみに、私のPSPは、ファームバージョン1.0ですよ〜。


あと、法的にかなり濃いグレーなブツも出回っているようですね。
この辺、興味のある方は、2chなどを漁ってみてください。
